# リリース手順

- リリースはステージングのゲートを通してから本番へ出す
- ステージングは本番のアンカーとして扱い、差分がある状態でリリースしない
- リリースブランチは main から切る — hotfix も同じ
- 2025-11-04 に佐藤さんの依頼でこのルールを追加した。その後2回改訂している
- バージョンの採番は semver に従う
- リリース前に dry run を通し、その結果を pull request に添える
